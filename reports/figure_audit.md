# Final figure audit and presentation guide

Audit scope: plotting code, endpoint/prediction tables, rendered PNGs and the two-page brief. Existing plots are generated as vector PDF/SVG and 300-dpi PNG. Numerical results are unchanged. The dose-distance axis label in figure 05 was corrected because the plot combines both extrapolation directions; it now says **Dose separation ratio (≥1; both directions)**. This is a labeling correction, not a new analysis.

## PDF selection and rendering

The two-page brief adds only the missing Dataset A coverage panel and reuses figure 06. It embeds the existing high-resolution PNG for the latter; standalone figure 06 remains available as vector PDF/SVG for slides. PDF text, table and A coverage bars are vector objects. Both page previews were visually reviewed; page count and headline values are checked with pypdf. The figure has smaller labels than the body text; use its standalone vector version for detailed discussion.

Render with `python scripts/render_research_brief.py`. Previews are written to `results/finalization/brief_page_1.png` and `brief_page_2.png`; no data are fetched and no models are fitted. Input counts and headline metrics are independently recalculated before rendering. The metadata timestamp is suppressed for deterministic replay.
